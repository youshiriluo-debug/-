外卖用户购买行为数据集说明文档
1. 数据集概述
本数据集为外卖用户购买行为数据，共包含 100,000 条用户记录。数据涵盖用户基本信息、历史消费行为、优惠券使用情况、配送距离以及购买结果等维度。

该数据集可用于：

数据预处理（缺失值处理、异常值处理、编码、标准化）

机器学习建模（分类、回归、多分类）

用户购买行为分析与可视化

模型对比与参数优化实验

数据特点：

数据分布合理，无极端异常值；

包含少量缺失值，符合真实业务数据特征；

目标变量包括二分类（是否购买）、连续值（购买金额）和多分类（购买等级）；

字段规范，记录完整，可直接用于分析与建模。

2. 字段说明（数据字典）
字段名	类型	说明	取值范围 / 示例
用户ID	整数	用户唯一编号	1 ~ 100000

性别	字符串	用户性别	男 / 女
历史订单数量	整数	历史累计订单数	均值约 18

3. 数据字段关系与业务逻辑
本数据集各字段之间遵循外卖业务中的常见规律，具体说明如下：

3.1 用户基本信息
年龄：取值集中在 18 至 65 岁之间，呈近似正态分布，均值约 35 岁。

性别：男性约占 52%，女性约占 48%。

3.2 历史行为特征
历史订单数量：反映用户长期活跃度，取值呈泊松分布特征，均值约 18 单。

购买频率：反映用户月均购买次数，均值约 7 次。

平均消费金额：集中在 15 至 150 元之间，均值约 50 元。

优惠券使用：约 40% 的用户使用优惠券。

配送距离：集中在 0.5 至 10 公里之间，均值约 3~4 公里。

4. 数据分布特征
根据数据集统计，主要特征如下：

指标	数值 / 说明
总记录数	100,000 条
购买比例	约 47% ~ 48%
年龄均值	约 35 岁
男性比例	约 52%
优惠券使用比例	约 40%
配送距离均值	约 3 ~ 4 公里
缺失值比例	每列约 1%
目标变量分布：

是否购买：0 和 1 二分类，比例大致均衡。

购买金额：仅购买用户有值，呈右偏分布，未购买用户为 0。

购买等级：在购买用户中，低、中、高各占约三分之一；未购买用户单独一类。

5. 数据质量说明
缺失值：年龄、配送距离、优惠券使用 各含约 1% 缺失，其余字段完整。

异常值：数据集已通过合理范围控制，不含极端异常值。年龄限制在 18~65 岁，配送距离限制在 0.5~10 公里，消费金额限制在合理范围。

一致性：购买金额与购买频率、平均消费金额逻辑一致；购买等级与购买金额对应。

完整性：数据记录规范，字段类型明确，可直接用于分析与建模。

6. 使用建议
6.1 数据预处理
缺失值处理：对 年龄、配送距离 可用均值或中位数填充；对 优惠券使用 可用众数填充，或将其作为单独类别处理。

异常值处理：可结合业务规则进一步校验，如年龄是否在 18~65、配送距离是否在 0~10km。

数据编码：性别 可做 One-Hot 编码或 Label Encoding；购买等级 可做有序编码（未购买=0，低=1，中=2，高=3）。

标准化：对 年龄、平均消费金额、配送距离、历史订单数量 等数值特征使用 StandardScaler 或 MinMaxScaler。

6.2 特征工程
可构造组合特征，如 消费金额 / 购买频率、历史订单数量 / 年龄 等。

对 配送距离 分箱（如 <2km、2-5km、>5km）作为类别特征。

对 购买频率 或 历史订单数量 进行分箱，转化为等级特征。

6.3 建模与评估
分类任务：以 是否购买 为目标，可使用逻辑回归、随机森林、XGBoost。

回归任务：以 购买金额 为目标，可使用线性回归、随机森林回归、XGBoost 回归。

多分类任务：以 购买等级 为目标。

评估指标：分类可用准确率、精确率、召回率、F1、ROC-AUC；回归可用 MSE、MAE、R²。

模型优化：交叉验证、网格搜索、特征选择。

6.4 可视化
可使用 ECharts、Matplotlib、Seaborn 对以下内容进行可视化：

用户年龄分布、性别比例；

购买频率与消费金额的关系；

优惠券使用对购买行为的影响；

不同配送距离下的购买比例；

三种模型（逻辑回归、随机森林、XGBoost）的性能对比。

7. 注意事项
本数据集为脱敏后的示例数据，仅用于学习、研究及项目演示，不代表真实业务数据。

如需调整数据规模，可修改数据文件中的记录数；如需调整缺失比例，可对缺失值进行相应处理。

数据集文件编码为 utf-8-sig，可直接用 Excel 打开，无乱码。
